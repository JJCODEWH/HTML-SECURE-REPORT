HTML 安全发布工具首页

按下面 3 步就可以完成上传、加密、查看和清理，全流程都在网页里完成。

使用教程（图文）

第 1 步：在管理页上传 HTML 并触发加密

进入管理页，填好仓库信息和管理员 PAT，选择 HTML 文件后点击“上传并触发加密”。系统会自动写入 incoming 并启动流程。

第 2 步：在查看页选择文档并用 KEY 解锁

切到查看页，选择文档，输入对应 KEY 后点击“解锁访问”，右侧即可显示完整 HTML 内容。

第 3 步：在管理页删除无效文件并同步清理

在删除区按文档或 Doc ID 删除后，会同步清理 incoming、key-map、payload 和 manifest，避免历史残留。

快捷入口

进入管理中心 进入查看中心

建议流程：先上传加密，再查 KEY，最后在查看页验证；验证完成后可在管理页执行删除清理，保持仓库干净。
